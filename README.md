## h. pertanyaan evaluasi

**24. apa fungsi html dalam pembuatan website?**
**jawaban:** menyusun kerangka dasar dan menampilkan konten pada halaman website.

**25. apa fungsi css dalam desain website?**
**jawaban:** mengatur tampilan visual, warna, huruf, dan tata letak website.

**26. apa yang dimaksud dengan navbar?**
**jawaban:** bilah menu navigasi untuk berpindah antar bagian halaman website.

**27. mengapa sebuah website sekolah membutuhkan menu navigasi?**
**jawaban:** memudahkan pengunjung mencari informasi sekolah dengan cepat dan terstruktur.

**28. apa fungsi atribut `href` pada elemen `<a>`?**
**jawaban:** menentukan alamat atau target tujuan saat tautan diklik.

**29. apa fungsi atribut `id` pada elemen html?**
**jawaban:** memberikan identitas unik pada elemen sebagai target tautan navigasi.

**30. apa fungsi perintah `display: flex` dalam css?**
**jawaban:** mengatur tata letak elemen agar sejajar dan fleksibel.

**31. apa kegunaan efek `:hover` pada navbar?**
**jawaban:** mengubah warna menu saat kursor diarahkan ke atasnya.

**32. mengapa website harus dirancang responsif?**
**jawaban:** agar tampilan tetap rapi di layar laptop maupun *smartphone*.

**33. apa kendala yang kalian hadapi saat membuat website sekolah dan bagaimana cara mengatasinya?**
**jawaban:** menu tidak berfungsi; diatasi dengan menyamakan penulisan `href` dan `id`.
